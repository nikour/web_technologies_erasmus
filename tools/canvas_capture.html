Canvas capture

Uniform script for the class data pool. Everybody renders exactly the same drawing; only the machine and the browser differ.

  1. Fill in the fields below (use a nickname, not your real name).
  2. Check that the image appeared.
  3. Click Save PNG and put the downloaded image into data/canvas/ of the shared repository.

Repeat this in every browser you have installed. One image per browser. There is nothing to compute here: the image itself is the data.
