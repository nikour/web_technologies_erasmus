Fonts capture

Uniform script for the class data pool. Everybody tests exactly the same list of candidate fonts, so the results can be pooled and compared.

  1. Fill in the fields below (use a nickname, not your real name).
  2. The page tests every candidate font automatically (takes a moment).
  3. Click Save fonts file and put the downloaded file into the shared repository (see the brief).

Repeat this in every setting you can: other browsers, a private window, with privacy extensions, Brave, Tor / Mullvad, other devices. One file per setting.
